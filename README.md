
### 本仓库只是暂时为个人使用，取自[原仓库](https://github.com/hicccc77/WeFlow)的最后一次commit版本，如若造成任何侵权，请联系删库。

从源码构建：

```bash
# 1. 克隆项目到本地
git clone https://github.com/hicccc77/WeFlow.git
cd WeFlow

# 2. 安装项目依赖
npm install

# 3. 运行应用（开发模式）
npm run dev
```
